# 🍏 TOFA7-AI (نظام تفاحة للذكاء الاصطناعي الذاتي)

> **نظام ذكاء اصطناعي حقيقي مبني من الصفر (From Scratch)**، يجمع بين شبكة محولات عصبية ذاتية (Self-Attention Micro-GPT)، ومصفوفات أوزان حقيقية، ومعمارية تفكير معرفية، وتصميم سيبراني برّاق مع إمكانيات صوتية وبصرية وبرمجية كاملة.

---

## 🌟 أبرز المميزات (Features)

1. 🧠 **ذكاء اصطناعي حقيقي 100% مبني من الصفر (Pure Neural Core)**:
   - تم بناء مكتبة العمليات الجبرية `Tensor` من الصفر (ضرب المصفوفات Matmul، دوال التنشيط ReLU و GeLU و Softmax، والتطبيع LayerNorm).
   - معمارية **Micro-GPT Transformer**: تضم طبقات تضمين الكلمات والمواقع (Token & Positional Embeddings)، وآلية الانتباه الذاتي متعدد الرؤوس (Multi-Head Self-Attention)، وقناع سببي Causal Masking، وتوليد ذاتي Autoregressive Generation.
   - شبكة **MLP (Multi-Layer Perceptron)** مع التدرج العكسي (Backpropagation) لتصنيف النوايا والمشاعر.
   - مجزئ ومرمز لغوي ثنائي اللغة (Bilingual Tokenizer) يدعم الحروف والكلمات العربية والإنجليزية والرموز.

2. 🔬 **مختبر الذكاء العصبي الحي (Interactive Neural Lab)**:
   - **مراقبة الدماغ البصري**: رسم تفاعلي مباشر للطبقات العصبية والسينابس (Synapses) مع نبضات ضوئية أثناء التفكير.
   - **مصفوفة الانتباه (Attention Heatmap)**: عرض مرئي لخريطة انتباه الكلمات لبعضها لحظياً.
   - **منحنى دالة الخسارة (Loss Curve)**: رسم بياني في الزمن الفعلي يوضح انخفاض الخطأ أثناء التدريب.
   - **تدريب مخصص**: إمكانية إدخال أو لصق أي نص لتدريب الشبكة العصبية عليه وتحديث مصفوفات الأوزان فوراً في المتصفح!

3. 💬 **المساعد الذكي الخارق (Smart Chat & Reasoning Engine)**:
   - محادثة ذكية وتوليد نصوص باللغتين العربية والإنجليزية.
   - حل المعادلات والمسائل الرياضية خطوة بخطوة عبر محرك جبري دقيق.
   - توليد وتصحيح الأكواد البرمجية (HTML/CSS/JS/Python) مع زر نسخ فوري للمحرر.

4. 🎙️ **التحدث والاستماع الصوتي (Voice AI)**:
   - استماع صوتي بالذكاء الاصطناعي (Speech Recognition) باللغة العربية والإنجليزية.
   - نطق صوتي تفاعلي ذكي (Speech Synthesis).
   - مؤثرات صوتية سيبرانية عبر Web Audio API بدون ملفات خارجية.

5. 🎨 **الاستوديو الإبداعي للفنون العصبية (Creative AI Studio)**:
   - توليد رسومات وأنماط ومجرات عصبية تفاعلية بناءً على الأوامر النصية.
   - إمكانية تحميل الرسومات بصيغة PNG عالية الدقة.

6. 💻 **محاكي الأكواد التفاعلي (Code Sandbox)**:
   - محرر أكواد حي مع إمكانية التشغيل الفوري للمواقع داخل إطار تفاعلي مع قوالب جاهزة (عداد تفاعلي، ساعة نيون).

7. 💎 **تصميم مستقبلي فائق الجمال (Cyber-Glassmorphism UI)**:
   - وضع ليلي عميق متوهج مع تأثيرات زجاجية (Glassmorphism) وحدود نيون متدرجة وتنسيق مريح للعين يدعم اللغة العربية (RTL) بشكل أصيل.

## 🚀 كيفية التشغيل (How to Run)

### الطريقة الأولى (الأسهل):
- فقط اضغط نقرتين مزدوجتين على ملف **`start.bat`**.
- سيفتح الموقع تلقائياً في المتصفح على الرابط: **`http://localhost:3000`**.

### الطريقة الثانية (عبر الأوامر):
```bash
npm start
```
أو:
```bash
node server.js
```
ثم افتح المتصفح على: `http://localhost:3000`
